Who It Serves

适合需要自己掌握账目的团队

从日常收入支出到月末结账，适合希望把账套留在自己电脑里、流程自己可控的经营者和会计人员。

初创公司

建账、记账、报表和进销项税一站完成，比订阅式 SaaS 更省钱。

小微企业

账套数据保存在本机，适合希望减少外部流转、保留内部经营数据的团队。

代账会计

多客户账套分开管理，便于在不同客户之间切换，并保留关键操作记录。

Core Workflow

覆盖建账、记账、审核、出表和备份

围绕小微企业常见账务流程设计，减少在多个文件、表格和工具之间反复切换。

多客户账套管理

支持多个客户独立建账，可区分一般纳税人 / 小规模纳税人、企业准则 / 小企业准则。

凭证录入与校验

内置工资、采购、销售、税费等常用凭证模板，并在录入时进行借贷平衡校验。

标准财务报表

审核后的凭证汇总生成资产负债表、利润表、所有者权益变动表和现金流量表，支持导出。

加密备份

备份文件采用 AES-256-GCM 加密，备份密码与登录密码分离，降低误传或外泄风险。

审计日志

凭证新增、审核、删除、封账、反结账和数据导入等操作留痕，便于事后核查。

账套导入

支持从 XLS / XLSX 文件导入科目、期初余额和凭证，减少迁移旧账时的重复录入。

Product UI

Questions

常见问题

可以先试用吗？ +

可以。每台电脑可免费试用 7 天，功能与正式版相同。试用结束后购买激活码即可继续使用。

订阅版和永久版有什么区别？ +

功能一致，只是授权时长不同。订阅版按年使用，永久版一次授权长期使用。

激活码可以在几台电脑上用？ +

一个激活码绑定一台电脑。更换电脑（硬件升级、重装系统等）时可解绑迁移，每年最多 2 次。

以后升级新版本要重新买吗？ +

不需要。所有版本更新免费，激活信息自动延续，无需重新输入激活码。

购买后多久收到激活码？ +

目前为人工发货。工作时间内通常 1 小时内、非工作时间 24 小时内发送到你的邮箱。

是否提供发票？ +

提供电子普通发票。购买后通过微信或邮件将抬头、税号发给客服，1-3 个工作日内开具。

数据存在哪里？ +

账套数据保存在用户自己的电脑中，不上传云端。软件激活时会向服务器提交机器特征码哈希，用于授权校验。

订阅到期后数据会受影响吗？ +

不会。到期后有 7 天宽限期；宽限期结束后进入只读模式，仍可查看和导出历史账目与报表。

可以退款吗？ +

软件提供 7 天免费试用，请在购买前充分体验。激活后的退款规则详见 最终用户许可协议。
