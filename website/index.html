可以先试用吗？ +

可以，每台电脑可免费试用 7 天，功能与正式版完全相同。 下载软件后启动，选择"免费试用"即可，无需付费、无需信用卡。 试用期结束后购买激活码即可继续使用。

订阅版和永久版有什么区别？ +

订阅到期不续费会怎样？ +

· 到期前 30 天：软件内会开始提示续费
· 到期后 7 天宽限期：仍可正常使用

· 随时续费即可恢复正常使用

你的数据永远属于你，不会因为不续费而丢失。

我不懂会计，能用吗？ +

可以。软件内置 23 种常用凭证模板（收入、支出、工资、税费等），套用模板即可。 借贷金额输入错会自动提示。但如果完全没有会计基础，建议先了解基本的借贷记账原理。

数据存在哪里？会不会泄露？ +

数据 100% 存在你自己的电脑（`%APPDATA%/WiseLedger/`），不上传任何云端。 只有在激活时会向服务器发一次机器特征码（SHA256 哈希，不含个人信息）。备份文件采用 AES-256-GCM 加密。

激活码可以在几台电脑上用？ +

一个激活码绑定一台电脑。更换电脑（硬件升级、重装系统换主板等）时可以解绑迁移， 每年最多 2 次。超过次数联系客服协助处理。

软件启动时 Windows 弹"未识别应用"警告是病毒吗？ +

不是病毒。因为暂未购买CA签名证书， Windows 对未签名的新软件都会弹这个提示。点【更多信息】→【仍要运行】即可正常安装。

不用。所有版本更新免费，激活信息自动延续，不需要重新输激活码或购买。

目前仅支持 Windows 10 / 11 64 位。Mac 版本正在评估中。
